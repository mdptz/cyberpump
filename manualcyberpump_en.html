1. HOW IT WORKS & WORKOUT/EXERCISE TYPES

CYBERPUMP is a digital personal trainer designed to manage workout routines with extreme precision in rest and work intervals. The application operates completely locally on your device: no data is sent to external servers, ensuring total privacy and full offline functionality.

Workout Modes (Execution Types)

Mode Description Best Used For
Standard Mode Exercises are performed in a linear sequence. All sets (Sets) of the first exercise are completed before advancing to the next exercise. Classic hypertrophy, barbell/dumbbell strength training, single-muscle routines.
Circuit Mode Exercises form a circuit. Exactly 1 set of each exercise is executed sequentially to complete 1 Cycle. The circuit repeats for the configured number of Cycles (Cycles). Calisthenics, HIIT, fat-loss conditioning, and station-based routines.

Exercise Types

  • Standard (Reps-Based): Measures work based on completed repetitions. At set start, perform your target reps and tap Complete Set to launch the configured rest timer.
  • Time-Based (Intervals/Timer): Work is driven by an active countdown timer (e.g., 60s). Upon completion, audio chimes and vibrations signal time-up. If interval rest is configured, an automatic pause timer starts between rounds.

Active Workout Player Flow

  • Keep Screen Awake (Wake Lock): The smartphone display remains active during the entire workout to prevent device sleep from freezing timers.
  • Voice Guidance & Audio Chimes: Synthesized voice prompts ("Work", "Rest", "Get ready") guide transitions and count down the final 5 seconds out loud.
  • Vibration & Banner Alerts: As timers hit 0s, the device vibrates and sends visual banner notifications even if operating in the background.

2. COMPLETE CONFIGURATION OPTIONS GUIDE

Routine & Table Configuration

  • Workout Title & Description: Routine title and optional training notes.
  • Circuit Cycles & Rest (Circuit Mode Only): Configure total circuit loops and extended rest intervals taken between cycles.
Field / Option Behavior & UX Details
⚡ Auto-start When Enabled (Checked): When this exercise begins, the app skips the transition screen ("Get Ready for Next Exercise") and immediately starts the first set or time-based timer.
When Disabled (Default): Pauses on the preview screen with the green "Start Exercise" button to allow time for equipment/weight setup.
Type Switch exercise measurement between repetition-based (Standard) or time-based (Time-Based).
Sets / Rounds Target set count (fixed to 1 set per round in Circuit Mode).
Reps & MAX Button Tapping rep values opens the numeric keypad.
Pressing MAX locks the input in read-only mode, signifying failure / AMRAP sets.
Weight Weight load in Kg or Lbs. Leave empty for Bodyweight exercises.
Rest / Work Interval Standard: Rest seconds between sets.
Time-Based: Work interval duration + optional secondary rest duration between rounds.

In-Workout Quick Controls & App Settings

  • ⚖️ Adjust Weight: Live-update weight during an active workout; automatically saves the change to your default workout template.
  • +10s Rest / Skip Rest ⏩: Instantly add 10 seconds to an active rest countdown or skip the rest period altogether.
  • Silent Mode: Accessible via the top navbar or Settings tab to disable voice prompts and audio chimes while retaining vibration and visual notifications.

3. EXPORT, IMPORT & DATA BACKUP

CYBERPUMP includes built-in tools to share workouts with workout partners, transfer your library across devices, or create offline backups without requiring account registration or cloud syncing.

Exporting & Sharing Workouts

Export Method How It Works
📱 Share via App Uses native device sharing to send exported workout routines directly via WhatsApp, Telegram, Email, or messaging apps.
📋 Copy Text String Generates a encoded JSON text string and copies it directly to your clipboard for quick pasting.
💾 Download JSON File Saves your complete local database as a portable .json file to local smartphone storage.
Single Routine Share Individual workouts can also be shared directly from the main My Workouts screen using the Share button on any workout card.

Importing Workouts

  • Paste String or Pick File: Import routines by pasting an exported JSON text string into the text box or selecting a saved .json/.txt file from your file manager.
  • Selective Import Modal: After parsing, a preview window displays all contained routines with checkboxes. You can select or deselect specific workouts before confirming the import.
  • Plan Limits & Slots:
    • Free Plan: Allows importing routines up to the free limit of 3 workouts total.
    • Premium Plan: Unlocks unlimited workout creation, cloning, and selective imports.
